# سایت داتیس آوان نیرو

سایت ایستا (HTML/CSS/JS) برای معرفی و فروش دیزل ژنراتور. نیازی به نصب یا سرور خاص ندارد؛ `index.html` را در مرورگر باز کنید یا کل پوشه را روی هاست آپلود کنید.

## صفحات
| فایل | محتوا |
|---|---|
| `index.html` | صفحهٔ اصلی: معرفی، جستجوی سریع ژنراتور، دسته‌بندی توان و نوع، محصولات منتخب، خدمات، پروژه‌ها، سؤالات متداول، فرم استعلام |
| `products.html` | کاتالوگ با فیلتر توان، نوع اجرا، برند موتور، جستجو و مرتب‌سازی |
| `product.html#id-...` (مثلاً `product.html#id-on-110p`) | صفحهٔ هر مدل: گالری، مشخصات فنی کامل، ویژگی‌ها، دیتاشیت قابل چاپ، فرم استعلام |
| `solar.html` | انرژی خورشیدی: انواع سیستم، ماشین‌حساب ظرفیت، فهرست پنل‌ها، مراحل اجرا، فرم درخواست |
| `energy.html` | تأمین برق صنایع از بورس: بررسی شرایط (دیماند ۱۵۰ کیلووات به بالا)، برق عادی/سبز/آزاد، جدول مقایسه، مراحل، فرم درخواست |
| `services.html` | خدمات، مراحل همکاری، نصب و اجاره |
| `about.html` | درباره ما، آمار، ارزش‌ها، پروژه‌ها، گواهینامه‌ها |
| `contact.html` | اطلاعات تماس و فرم استعلام قیمت |
| `credits.html` | منابع و مجوز تصاویر |

## ویرایش اطلاعات (فقط یک فایل)
همهٔ اطلاعات در `assets/js/data.js` است:
- **`SITE`**: تلفن، موبایل، واتس‌اپ، ایمیل، نشانی، ساعات کاری، آمار شرکت
- **`PRODUCTS`**: فهرست مدل‌ها. برای افزودن مدل جدید یک آبجکت کپی و مقادیرش را عوض کنید. صفحهٔ محصول، کاتالوگ و فیلترها خودکار به‌روز می‌شوند.
- **`SERVICES`**، **`PROJECTS`**، **`FAQ`**: خدمات، پروژه‌ها و سؤالات متداول
- **`SOLAR_PANELS`**، **`SOLAR_SYSTEMS`**، **`SOLAR_CALC`**، **`SOLAR_FAQ`**: پنل‌ها، انواع سیستم خورشیدی، ضرایب ماشین‌حساب و سؤالات
- **`ENERGY`**، **`ENERGY_PLANS`**، **`ENERGY_COMPARE`**، **`ENERGY_STEPS`**، **`ENERGY_FAQ`**: حداقل دیماند، تعریف برق عادی/سبز/آزاد، جدول مقایسه، مراحل و سؤالات بورس برق (این متن‌ها باید با واحد بازرگانی و مقررات جاری تطبیق داده شوند)

همهٔ مواردی که باید با اطلاعات واقعی جایگزین شوند با `TODO` علامت خورده‌اند.

## عکس‌ها
عکس‌ها در `assets/img/` هستند. برای استفاده از عکس محصولات خودتان، فایل را در همین پوشه بگذارید و نامش را در فیلد `images` مدل مربوطه در `data.js` بنویسید (عرض حدود ۱۲۰۰ پیکسل، نسبت ۴:۳).

## فرم‌ها
به‌طور پیش‌فرض، فرم استعلام پیام را در برنامهٔ ایمیل کاربر آماده می‌کند. برای دریافت مستقیم درخواست‌ها، آدرس یک سرویس فرم (مثل Formspree یا API خودتان) را در `SITE.formEndpoint` قرار دهید.

## نکات فنی
- فونت وزیرمتن و آیکون‌ها داخل سایت هستند و به CDN خارجی وابسته نیستند (مناسب کاربران داخل ایران).
- راست‌چین، واکنش‌گرا (موبایل تا دسکتاپ)، قابل استفاده با کیبورد و سازگار با تنظیم «کاهش انیمیشن».
- دکمهٔ «دریافت دیتاشیت» در صفحهٔ محصول، یک برگهٔ مشخصات تمیز برای چاپ یا ذخیرهٔ PDF می‌سازد.
