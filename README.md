# داتیس آوان نیرو — وب‌سایت

وب‌سایت شرکت داتیس آوان نیرو: ژنراتور دیزلی و گازی، انرژی خورشیدی و تأمین برق صنایع از بورس انرژی.

سایت ایستا است (HTML، CSS و JavaScript بدون فریم‌ورک و بدون مرحلهٔ build). برای دیدن آن، `site/index.html` را در مرورگر باز کنید یا پوشهٔ `site/` را روی هر هاست ایستا آپلود کنید.

## ساختار

```
site/                 کد سایت (همین پوشه روی هاست قرار می‌گیرد)
  index.html          صفحهٔ اول
  products.html       کاتالوگ ژنراتور دیزلی و گازی
  product.html        صفحهٔ مشخصات هر مدل (ژنراتور یا پنل خورشیدی)
  solar.html          انرژی خورشیدی و ماشین‌حساب ظرفیت
  energy.html         تأمین برق صنایع از بورس
  services.html, about.html, contact.html, credits.html
  assets/css/         استایل
  assets/js/data.js   همهٔ اطلاعات قابل ویرایش (تماس، محصولات، متن‌ها)
  assets/js/app.js    منطق صفحات
  assets/img/         تصاویر و لوگو
  assets/fonts/       فونت وزیرمتن
logo/                 فایل‌های اصلی لوگو
```

راهنمای ویرایش محتوا: [EDITING.md](EDITING.md)

## انتشار امن

- فقط **محتوای پوشهٔ `site/`** را روی هاست آپلود کنید؛ هرگز کل مخزن (پوشهٔ `.git` و `logo/` نباید عمومی شوند).
- `site/.htaccess` برای هاست‌های Apache/LiteSpeed و `site/_headers` برای Cloudflare Pages/Netlify هدرهای امنیتی (CSP، جلوگیری از قرار گرفتن سایت در iframe، nosniff و ...) را تنظیم می‌کنند. بعد از انتشار، در ابزار توسعه‌دهندهٔ مرورگر (تب Network) بررسی کنید که این هدرها روی صفحه‌ها برگردانده می‌شوند.
- بعد از فعال شدن SSL، بخش تغییر مسیر HTTP به HTTPS را در `.htaccess` از حالت توضیح خارج کنید.
- اگر `formEndpoint` را در `data.js` تنظیم کردید، دامنهٔ آن را به `connect-src` در هر دو فایل اضافه کنید.
- در صفحه‌ها اسکریپت درون‌خطی (inline) نگذارید؛ CSP فقط فایل‌های JS خود سایت را اجرا می‌کند.

## نکته‌ها

- همهٔ اطلاعات تماس، آمار، مشخصات محصولات و متن‌های بورس برق نمونه هستند و با `TODO` در `site/assets/js/data.js` مشخص شده‌اند.
- منابع و مجوز تصاویر در `site/credits.html` آمده است. فونت وزیرمتن تحت مجوز SIL OFL و آیکون‌ها از Lucide (مجوز ISC) هستند.
